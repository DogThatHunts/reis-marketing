## 5. Decisions

- **Length:** the Q&A version runs past the original 30-second target; 42.7s is accepted.
- **Region name:** "Myrtle Beach and Brunswick County".
- **Pronunciation:**
  - **REIS:** the letters run together with no pauses. Write "R E I S" in the voiceover text (spaces, no periods); "REIS" is read as "rise", and periods add pauses.
  - **DR Horton:** said with no pause between D and R. Write "DR Horton" in the voiceover text; captions and screens use the correct spelling, "D.R. Horton".
  - **Price:** spoken as "three seventy-five"; the screen shows $374,680.
- **Naming:** all data comes from public sources, so builders and communities can be named.
- **Logo and graphics:** the PDF logo and the report's charts, as they are, for now. Improve them if the concept is taken further.
- **Call to action:** reis-myrtlebeach.com is a **made-up placeholder** (the user's version, REIS_myrtle_beach.com, isn't a valid domain). Replace it before posting anywhere public.
- **Voices:** Kokoro-82M (free, runs locally, Apache 2.0 licence allows commercial use). ElevenLabs, including a Southern-accent test, is deferred.
- **Music:** placeholder track "Inspired" by Kevin MacLeod (CC BY 4.0, credit required).
- **Parked:** 10 single-voice versions (`myrtle_beach_teaser_mono_<voice>.mp4`). The preferred single voice was `af_heart`.

## 6. Production (`video/`)

- `scripts/qa.json` and `scripts/mono.json` hold the voiceover text, captions (question or answer style), and which scene shows during which lines. The timing of the on-screen switches (`split`, `answer_at`) is also set there.
- `python vo.py scripts/qa.json --speed 1.2` renders the voiceover segments with Kokoro into `vo/qa/`. It needs `brew install espeak-ng` and the Kokoro model files in `KOKORO_DIR`.
- `python render.py scripts/qa.json` draws the frames with Pillow, encodes with ffmpeg, and mixes the voiceover over music that dips under the voice. Output: H.264 + AAC 48 kHz, index at the start of the file, swapped into place only when complete.
- Full setup steps are in the repo README. The Python environment and Kokoro model used in this session lived in a temporary folder, so they must be reinstalled before the next render.
